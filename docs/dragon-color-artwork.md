# Dragon color artwork record

Generated on October 3, 2026 with the built-in ImageGen tool. These are original editorial illustrations for this independent website, not official game artwork or screenshots. The six color names follow the [official Dragonkind color collections](https://rebeccayarrosshop.com/pages/dragonkind), linked from the [author's FAQ](https://rebeccayarros.com/faqs). This source does not establish a complete current result catalog or outcome odds.

Each portrait was generated separately and visually inspected. Sharp resized and encoded the selected images as 960 × 640 WebP, quality 82. No recoloring was used. Portraits appear on the homepage, the dragon result guide and matching fan quiz results. Captions describe our artwork rather than official dragon traits.
